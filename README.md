# towfik plugins

Claude Code plugin marketplace by [Towfik](https://github.com/towfikul-islam).

## Install

Add this marketplace once inside Claude Code:

```
/plugin marketplace add towfikul-islam/plugins
```

Then install any plugin:

```
/plugin install trello@towfik
```

## Available plugins

| Plugin | Description |
|---|---|
| [`trello`](https://github.com/Strong-Force-Analytics/trello-skill) | Direct Trello API access — read cards, post comments, upload files, download attachment bytes |
